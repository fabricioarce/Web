# Roadmap futuro

## Siguiente contenido

- Añadir proyectos de software e investigación mediante Markdown tipado.
- Incorporar imágenes optimizadas, evidencias y demos.
- Crear y publicar CV bilingüe.
- Revisar traducciones con voz personal consistente.

## Experiencias

- Juego lógico opcional para desbloquear un detalle o Easter egg, nunca el único acceso al contacto.
- Calendario de actividad alimentado por datos estables y cacheados.
- Estadísticas reales de Codeforces y AtCoder sin perjudicar rendimiento ni privacidad.
- Página de detalle para cada proyecto.

## Publicación

- Blog bilingüe con Astro Content Collections, RSS y páginas por etiqueta.
- Panel administrativo solo si mantener Markdown deja de ser práctico.
- Appwrite Storage únicamente si se necesita carga remota de imágenes.
- Analítica respetuosa de privacidad y sin cookies, si se considera necesaria.

## Criterio

Estas funciones se implementarán después de validar el sitio principal. La navegación, el contenido y el contacto nunca dependerán de un juego, una terminal ni una API externa.
